# Battle-Blaster — Game Tutorial

## Objective

Battle-Blaster is a tank combat game where you must destroy all enemy turrets in each level.

The game contains **3 levels**. After clearing a level, the next level loads automatically. If the player is defeated, the current level is restarted.

## Controls

### Tank Movement

| Key | Action |
|---|---|
| **W** | Move forward |
| **S** | Move backward |
| **A** | Rotate tank left |
| **D** | Rotate tank right |

### Aiming

- **Mouse** — Aim the tank's cannon.
- The cannon follows the mouse position to determine the aiming direction.
- The aiming direction moves together with the tank as the tank rotates.

### Shooting

- **Left Mouse Button** — Fire a projectile.
- The projectile travels forward in the direction the cannon is aiming.

## Gameplay

1. Each level begins with a short countdown: **3 → 2 → 1 → Go!**
2. Move the tank using **W, A, S, D**.
3. Aim the cannon with the **mouse**.
4. Press **Left Mouse Button** to fire.
5. Enemy turrets automatically aim and fire at the player's tank when within range.
6. Destroy **all enemy turrets** to complete the level.
7. After a short victory sequence, the next level loads automatically.
8. Complete all **3 levels** to finish the game.
9. If the tank is destroyed, the current level starts again.
